Universal Cart is for the web. MX is for files.

Google's Universal Cart launched at I/O 2026 with seven retailers: Nike, Sephora, Target, Ulta Beauty, Walmart, Wayfair, and the Shopify ecosystem including Fenty and Steve Madden. If you are one of them, you have a clear path forward. If you are not, the announcement raises a question that goes well beyond the cart.

What happens to a file once it leaves the page it was published on?

A price quoted in an agent response three weeks later. A returns policy attached to an email. A contract clause cited in a dispute. An accessibility statement pulled from an archive by an EAA investigator. An AI-drafted letter handed to a client on paper. Each one is a file or fragment that has travelled away from its source, and each one either carries enough metadata to stand on its own, or does not.

The Universal Commerce Protocol cannot describe a returns policy. AP2 cannot describe an accessibility audit. Neither was designed to. They cover commerce on Google's surfaces. The broader question, files that need to remain meaningful anywhere they end up, needs an open answer.

That answer is MX. The new post walks through Universal Cart, UCP, and AP2 from the perspective of everyone outside the partner ring, and shows how MX, COGs, and REGINALD handle the same problem across any file, any carrier, any destination, including paper.
