Ask the Image What It Knows

3 July 2026 · Tom Cranstoun · 7 min read

This is our logo. It is also, unashamedly, an advert for us.

Doğu Abaris designed it. I approved his design. Maxine, my AI partner, published it into the site's assets and embedded its metadata. I approved the published result. Four steps, two humans, one machine, and every one of them is recorded inside the file itself. Not in a spreadsheet somewhere, not in an email thread nobody will find in a year. In the PNG.

Most images cannot do this. A picture lands in an assets folder, looks lovely on the page, and knows nothing. Who made it? Who said it could be published? Was a machine involved? The file has no answer, so every system that meets it later has to guess or ask around. We think the file should just say.

The script that asks

So here is the tool we use to ask. It is a single Node script, and it works on any image on your machine, not only ours. It needs two things installed: Node.js and ExifTool, Phil Harvey's veteran metadata reader that almost every serious imaging pipeline already leans on.

Run it and you get one JSON document with everything the file declares:

  • allMetadata - the complete dump: every EXIF, XMP, and file-level field ExifTool can find. Not a curated selection. All of it.
  • mx - the MX block, if the image carries one: title, author, reuse policy, how the content was created, where the canonical copy lives. This travels in the image's XMP packet, the metadata carrier Adobe designed for exactly this job and later became an ISO standard.
  • provenance - the chain of who did what: the embedded record plus the sidecar files, when they exist.

And it never scolds you. If the MX block is missing, the script does not error; it reports "Not Present - read https://mx.allabout.network/books/". If it is there, you get "Read the books https://mx.allabout.network/books/" instead. Either way you know where the story continues.

Copy, save, run

Copy the whole block below into a file called export-asset-metadata.cjs (the Copy button on the block puts it on your clipboard in one click), then run:

node export-asset-metadata.cjs your-image.png

#!/usr/bin/env node
/**
 * export-asset-metadata.cjs
 * Export everything an asset declares about itself as one JSON document:
 * the full metadata dump (every EXIF, XMP, and file field exiftool can
 * read), the MX block, the embedded AI provenance payload, and the
 * adjacent sidecar pair.
 *
 * Needs Node.js and exiftool (https://exiftool.org/).
 * Usage: node export-asset-metadata.cjs <image> [--compact]
 */

'use strict';

const fs = require('node:fs');
const path = require('node:path');
const { execFileSync } = require('node:child_process');
const { pathToFileURL } = require('node:url');

const BOOKS_URL = 'https://mx.allabout.network/books/';
const NOT_PRESENT = `Not Present - read ${BOOKS_URL}`;
const PRESENT = `Read the books ${BOOKS_URL}`;

// Inside MX-hub the shared library is the authority; when the script has been
// pasted elsewhere the require fails and every read falls back to exiftool.
let lib = null;
try { lib = require('./lib/asset-metadata.cjs'); } catch (_) { /* standalone mode */ }

function readAllMetadata(absPath) {
  try {
    const out = execFileSync('exiftool', ['-j', '-a', '-G1', absPath], { encoding: 'utf8' });
    const parsed = JSON.parse(out);
    return parsed && parsed[0] ? parsed[0] : null;
  } catch (_) {
    return null; // exiftool absent or unreadable file - reported, never fatal
  }
}

function mxFromDump(dump) {
  const mx = {};
  for (const [key, value] of Object.entries(dump || {})) {
    if (key.startsWith('XMP-mx:')) {
      const name = key.slice('XMP-mx:'.length);
      mx[name.charAt(0).toLowerCase() + name.slice(1)] = value;
    }
  }
  return mx;
}

function parseJsonOrNull(raw) {
  try { return JSON.parse(raw); } catch (_) { return null; }
}

// The sidecar naming convention: strip the asset's extension, add the pair.
function readSidecarsByConvention(absPath) {
  const base = absPath.replace(/\.[^.]+$/, '');
  const read = (p) => (fs.existsSync(p) ? parseJsonOrNull(fs.readFileSync(p, 'utf8')) : null);
  return {
    ai: read(`${base}.provenance.ai.json`),
    deterministic: read(`${base}.provenance.deterministic.json`),
  };
}

async function exportAsset(absPath) {
  const allMetadata = readAllMetadata(absPath);

  let mx; let verdict; let embedded; let sidecars;
  if (lib) {
    mx = await lib.readAssetMx(absPath);
    verdict = await lib.classify(absPath);
    embedded = await lib.readAssetProvenance(absPath);
    const provModulePath = path.join(lib.REPO_ROOT, 'mx-reginald', 'lib', 'provenance.js');
    const { readProvenance } = await import(pathToFileURL(provModulePath).href);
    sidecars = readProvenance(absPath) || { ai: null, deterministic: null };
  } else {
    mx = mxFromDump(allMetadata);
    verdict = Object.keys(mx).length ? 'present' : 'missing';
    embedded = mx.provenanceAiPayload ? parseJsonOrNull(mx.provenanceAiPayload) : null;
    sidecars = readSidecarsByConvention(absPath);
  }

  const mxPresent = mx && Object.keys(mx).length > 0;
  return {
    asset: lib ? lib.relFromRepo(absPath) : absPath,
    verdict,
    books: mxPresent ? PRESENT : NOT_PRESENT,
    mx: mxPresent ? mx : NOT_PRESENT,
    allMetadata: allMetadata ||
      'exiftool not found - install it from https://exiftool.org/ to read the full metadata dump',
    provenance: {
      embedded: embedded || NOT_PRESENT,
      sidecars: {
        ai: sidecars.ai || NOT_PRESENT,
        deterministic: sidecars.deterministic || NOT_PRESENT,
      },
    },
  };
}

async function main(argv) {
  const args = argv.slice(2);
  if (args.includes('-h') || args.includes('--help') || args.length === 0) {
    process.stdout.write('usage: export-asset-metadata.cjs <asset-path> [--compact]\n');
    return args.length === 0 ? 2 : 0;
  }
  const compact = args.includes('--compact');
  const file = args.find((a) => !a.startsWith('--'));
  if (!file) {
    process.stderr.write('export-asset-metadata: pass an asset path\n');
    return 2;
  }
  const abs = path.resolve(process.cwd(), file);
  if (!fs.existsSync(abs) || !fs.statSync(abs).isFile()) {
    process.stderr.write(`export-asset-metadata: no such file: ${file}\n`);
    return 2;
  }

  const doc = await exportAsset(abs);
  process.stdout.write(JSON.stringify(doc, null, compact ? 0 : 2) + '\n');
  return 0;
}

if (require.main === module) main(process.argv).then((code) => process.exit(code));
module.exports = { exportAsset, main };

One design note, because it matters for trust: the script never invents anything. It reads what the file carries and reports absence as absence. A reader running it on our logo gets the same answer we do, with no privileged access and none of our tooling installed.

What our logo says

Here is a trimmed version of what comes back when we point the script at the logo above:

{
  "asset": "mx-site/blog/assets/ddt-logo.png",
  "verdict": "clean",
  "books": "Read the books https://mx.allabout.network/books/",
  "mx": {
    "title": "Digital Domain Technologies logo",
    "author": "Doğu Abaris",
    "provenanceOrigin": "human-directed",
    "contentPolicy": "Brand asset. Reuse only with permission from Digital Domain Technologies Ltd; do not alter the mark."
  },
  "provenance": {
    "embedded": {
      "steps": [
        { "stepId": "asset.created",        "agent": "Doğu Abaris" },
        { "stepId": "asset.approved",       "agent": "Tom Cranstoun" },
        { "stepId": "asset.published",      "agent": "Maxine" },
        { "stepId": "asset.final-approval", "agent": "Tom Cranstoun" }
      ]
    }
  }
}

Read that chain again. A designer created the work. A human approved it. A machine published it. A human approved the published result. When an AI acts in your pipeline, the honest record is not "an AI did this" and it is not silence either. It is the whole sequence, with the humans in it, in a form the next machine can read without asking anyone.

Try it on your own images

Point the script at your company logo. Your product photography. The hero image on your homepage. My bet: "Not Present - read https://mx.allabout.network/books/", over and over. That is not a criticism of you; it is the default state of nearly every image on the web. The file does its visual job perfectly and carries no memory at all.

The fix is cheaper than it looks, and the moment to apply it is when an asset is born, not three years later when someone asks which of nine hundred images you actually have the rights to. That practice, making files that explain themselves to machines, is what the MX books teach. Start with the logo you already have. Ask it what it knows, and then teach it to answer.
