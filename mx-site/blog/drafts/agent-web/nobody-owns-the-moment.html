Nobody Owns the Moment

20 September 2026 · Tom Cranstoun · 5 min read

Everyone's asking who'll own the agent in your pocket. Apple, Google, OpenAI, Meta, xAI: whichever one ships the assistant that turns "I want" into "done" with the fewest taps, the thinking goes, owns the next decade the way the phone owned the last one. I think that question arrives too early. Before you can ask who owns the agent, you have to ask what it reads.

The Distance Moves

The promise of an agent is that the gap between wanting something and getting it closes. You say "book the table" and it's booked. The gap only closes, though, if the agent can find the restaurant, tell it's the right one, read the menu, check tonight's availability, and pay. Every one of those steps depends on what the restaurant has published, and how.

The typical business website is written for a person with a mouse. Send an agent to it and it meets cookie banners, menus that only render with JavaScript, prices with no unit, and pages with no way to tell whether they were updated a week ago or three years ago. The agent doesn't give up; it guesses, or it goes elsewhere. The gap hasn't closed so much as moved, from the customer to the business.

The businesses that close it publish content an agent can use directly. In MX, the record that carries that content is a COG, for Community Owned Governance Standard, and the name does the explaining. Community owned: the rules for what a COG contains are set by an open standards body, not by one vendor. Governance: the point isn't the content itself but what it declares about itself, meaning who published it, when, what it is, and what may be done with it. Standard: like JSON, the word names both the specification and any record that conforms to it. In practice a COG is a short plain-text record attached to a page or document, so software reads it without a browser. It's signed, so the agent can check who published it, and dated, so it can tell whether it's still true. Carrier-neutral, attested, current. A restaurant with a COG for tonight's menu gets booked. A restaurant with a PDF behind a pop-up doesn't.

This is the real disintermediation risk, and it isn't the one people fear. The fear is that the agent recommends a competitor; the likelier outcome is that it never sees you at all.

What the Agent Changes

Who the buyer is. When the agent acts, it pays. Pricing has to be legible to software, and settlement has to happen inside the request rather than on a checkout page designed for a thumb. The HTTP 402 status code, named Payment Required and still held in reserve by the HTTP specification, and the x402 work Coinbase (n.d.) built on it exist for this reason. If the agent can't read the price, the sale doesn't happen.

What engagement means. Engagement has meant attention: time on page, scroll depth, return visits. An agent has no attention to give. It asks whether it can find this, whether it can verify who published it, and whether it's current. If the answers are yes, it comes back. If not, it doesn't. Loyalty becomes a property of the source, not of a brand voice.

What consent means. A pop-up that gets swatted away is theatre. If consent is going to mean anything in an agent flow, it has to travel with the content as governance metadata: what may be used, by whom, and for how long. Written that way, the terms travel with the transaction and can be checked after it.

What happens to the data afterwards. Every result the agent returns should carry where it came from and when, so the person it acts for can review it. Human in the loop is a principle, not a feature toggle, and provenance is what makes it work. I wrote about the reader's side of this in Provenance You Can See: evidence the person can verify themselves, rather than assurances from inside the deal.

Why One Agent Won't Win

The "who owns the agent" question carries assumptions I think are wrong.

The first is that the future is dozens of agents spinning up disposable applications to get things done. That's a compute-heavy picture. A better-structured web needs fewer agents doing less inference to reach the same answer, which is cheaper for everyone and less wasteful.

The second is that one agent owns the moment. Phones didn't end with one owner. Neither did the internet. Both ended with standards that let many parties take part, and the value went to whoever the standards made findable and trustworthy. The durable position is being the source every agent comes back to, and being part of the body that defines what "attested" means. That layer no single vendor should own for good. MX is a private protocol, created for the MX books and stewarded by CogNovaMX while we run it live as a test. It is published under the MIT licence, so anyone may implement it, and it will be donated to The Gathering as an open standard. A registry such as REGINALD holds the attestation records so an outsider can check them; after the donation, the definition of what counts as attested sits with the Gathering, not with us.

The honest answer to "who will be trusted" is whoever can prove it, so start where the proof is cheapest to produce. Pick the one thing your customers most often want from you, tonight's menu or the current price list, and publish it as a COG: plain text, signed, dated. Then bring what you learn to The Gathering, where the rules for that record are still being written.
