# Published Provenance Records

Publicly served `.provenance.ai.json` records for CogNovaMX's own published PDFs. Each is the same JSON the document embeds in its XMP packet; hosting it here is what makes the badge's "Walk this document's evidence chain" link resolve in one click. Confidential client deliverables never appear here - their chains travel inside the file and are walked locally in the inspector.
