Learn MX.

The practice of adding metadata and instructions to internet assets so AI agents don't have to guess.

When an AI agent visits your website, it reads the HTML — not the pixels. If your content lacks semantic structure, metadata, and explicit instructions, the agent guesses. When it guesses, it hallucinates. MX eliminates the guesswork. These resources explain what MX is, why it matters, and how to apply it — from core principles to common mistakes to the full set of MX patterns.
