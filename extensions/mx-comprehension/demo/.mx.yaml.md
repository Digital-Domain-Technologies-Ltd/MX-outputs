# MX Comprehension Probe - demo pages

## Purpose and Role

This folder holds the matched page pair the MX Comprehension Probe extension reads for the MozFest 2026 demo. Both pages describe the same fictional medication. A human understands either one. A machine does not: the structured page hands it the facts, the stripped page hands it a guess.

| File | Layer | Extension |
|---|---|---|
| `treatment-structured.html` | Full machine-readable layer: MX frontmatter, per-field meta, Schema.org JSON-LD, visible provenance panel | `.html` |
| `treatment-hostile.htm` | None. Hostile-web furniture: non-semantic divs, hidden tabs, an image with no alt, cookie wall, promos | `.htm` |
| `index.html` | Landing page linking both, with the three probe questions and run instructions | `.html` |
| `demo.css` | Shared stylesheet for all three pages | - |
| `dose-table.png` | Placeholder image the stripped page locks its dosing detail inside | - |

The `.htm` / `.html` split is a deliberate mnemonic: **htm is the stripped page, html is the full one.**

## Safety

All content is fictional. "Veltrazine", "Calder's syndrome", and "Northgate Therapeutics" do not exist. The planted dosage error is there to be caught by the structured page's provenance layer, never to be acted on. Every page carries a visible "fictional demo content - not medical advice" banner.
