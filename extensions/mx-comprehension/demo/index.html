Fictional demo content - not medical advice. Both pages describe a made-up medicine. The planted dosage error exists to be caught.

Facts, or a guess

Two pages describe the same fictional medication. A human understands both. A machine does not: one page hands it the facts, the other hands it a guess.

Load the MX Comprehension Probe extension, open each page, and ask the same question of both. The probe reads only what the page carries and answers from that alone. It never looks for MX. The difference in the answer is the page's doing.

Structured page

Full machine-readable layer

Carries per-section authorship and clinical review, a clinician-verified dose, and an explicit disclosure of the one AI-drafted paragraph. The machine answers with a list of facts.

Stripped page

The hostile web

Same words for a human, but no authorship, no review, no disclosure, no structured data. Facts buried in tabs and images, padded with cookie walls and promos. The machine can only guess.

Ask both pages the same three questions

  1. Who wrote this page, when, and has a qualified person reviewed it?
  2. Is the dosage on this page safe to act on - who verified it and when?
  3. Was any part of this written by AI? Which part, and by which model?

Run it

Serve this folder over localhost, then open each page in its own tab:

python3 -m http.server 8000 from mx-outputs/extensions/mx-comprehension/demo

Point an on-device model at it: Chrome or Edge built-in. Setup is in the extension README.
