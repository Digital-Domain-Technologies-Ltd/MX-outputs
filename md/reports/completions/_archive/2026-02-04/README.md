## About Session Summaries

Session summaries are automatically generated using the `/mx-endsession` skill when wrapping up work sessions. Each summary documents:

- What was accomplished
- Files modified
- Testing and verification
- Technical decisions
- MX principles applied
- Next steps

## File Naming Convention

```
session-summary-{YYYY-MM-DD}T{HH-MM}.md
```

Example: `session-summary-2026-02-04T13-30.md`
