## Technical Details

### Perl Script Enhancement

The key technical challenge was handling existing `mx:` sections in YAML frontmatter without creating duplicates:

**Solution:**

```perl
# Check if mx: section already exists
if ($yaml_content =~ /^mx:/m) {
    # Add new fields to existing mx: section
    $yaml_content =~ s/(^mx:\n)/mx:\n  generated-from: "$source_path"\n  generated-date: "$timestamp"\n  purpose: "..."\n  process: "emoji-cleaning"\n/m;
} else {
    # No mx: section exists, add one at the end of frontmatter
    $yaml_content .= "\nmx:\n  generated-from: \"$source_path\"\n  generated-date: \"$timestamp\"\n  purpose: \"...\"\n  process: \"emoji-cleaning\"";
}
```

This approach:

- Detects existing mx: sections via regex pattern matching
- Inserts new fields immediately after mx: header if exists
- Appends new mx: section to end of frontmatter if not exists
- Preserves all original YAML fields

### Environment Variable Passing

Used bash environment variables to pass data to Perl:

```bash
TIMESTAMP="$timestamp" SOURCE_PATH="$source_path" perl -0777 -pe '...'
```

This avoids complex escaping issues with paths containing spaces or special characters.
