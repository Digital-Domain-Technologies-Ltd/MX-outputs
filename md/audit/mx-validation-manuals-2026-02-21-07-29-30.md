## How to Fix Validation Errors

### Missing Required Fields

Add missing fields to YAML frontmatter:

```yaml
---
mx:
  purpose: "Brief description of what this file does"
  audience: "human"  # or "machine" or "both"
  stability: "stable"  # experimental, unstable, stable, frozen
  runbook: "Read this context when its topic is relevant to the current task"
  ai:
    contextProvides:
      - "What information this file provides"
---
```

### Relative Path Violations

Replace relative paths with repo-root-relative paths:

```yaml
# ❌ WRONG:
refersTo:
  - ../../some-file.md

# ✅ CORRECT:
refersTo:
  - datalake/publications/mx-books/mx-appendices/some-file.md
```

**Why:** Repo-root-relative paths work regardless of where files are moved within the repository.
