# MX Configuration

## Purpose and Role

Shared configuration files, specifications, and standards. Centralize all MX-related configuration, specifications, and system documentation.

Configuration centralized here serves both build processes and runtime requirements across all MX projects.

## How to Use This Folder

Configuration files define standards, specifications, and settings. Changes here propagate to all dependent systems.

## Architecture Context

Single source of truth for MX configuration. Referenced by build scripts, validation tools, and documentation generation.

## For AI Agents

Configuration files are machine-readable. Respect format specifications and validate changes before committing.
