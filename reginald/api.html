API Reference

Base URL: https://reginald.allabout.network

Read Endpoints Public

  • GET /index.json Full registry index
  • GET /api/v1/stats.json Registry statistics
  • GET /api/v1/publishers.json Registered publishers
  • GET /api/v1/namespaces.json Namespace directory
  • GET /api/v1/namespaces/{ns}/cogs.json COGs in a namespace
  • GET /cogs/{ns}/{name}/latest.json Pointer record (latest version)
  • GET /api/v1/public-key.pem Registry Ed25519 public key
  • GET /llms.txt AI-readable registry summary

Write Endpoints Auth Required

  • POST /api/v1/subscribe Create Stripe checkout session (new publishers)
  • POST /api/v1/register Register or update a namespace (Bearer token)
  • GET /api/v1/publisher/status Check subscription and listing status (Bearer token)
  • POST /api/v1/publisher/token/rotate Generate new API token, revoke old (Bearer token)

Authentication

Read endpoints require no authentication. Write endpoints require a Bearer token issued during subscription:

Authorization: Bearer reg_your64hexcharshere...

Tokens are generated at subscription time and can be rotated via the token rotation endpoint. Token format: reg_ prefix + 64 hex characters.
