REGINALD

Registry for Genuine Information, Notarised Authentication, and Legitimate Documentation

REGINALD is a pure DNS-like resolver for machine-readable documentation. It maps COG identifiers to publisher-hosted content URLs. REGINALD does not host content — each publisher serves their own COGs.

API Endpoints

  • GET /index.json — Full registry index
  • GET /api/v1/stats.json — Registry statistics
  • GET /api/v1/publishers.json — Registered publishers
  • GET /api/v1/namespaces.json — Namespace directory
  • GET /api/v1/namespaces/{ns}/cogs.json — COGs in a namespace
  • GET /cogs/{ns}/{name}/latest.json — Pointer record (latest version)
  • GET /api/v1/public-key.pem — Registry public key
  • GET /llms.txt — AI-readable registry summary LLM

Resolution Flow

  1. Discover namespaces via /api/v1/namespaces.json
  2. List COGs in a namespace via /api/v1/namespaces/{ns}/cogs.json
  3. Fetch pointer record via /cogs/{ns}/{name}/latest.json
  4. Follow canonical_url to retrieve content from the publisher
  5. Verify content_hash and certificates
