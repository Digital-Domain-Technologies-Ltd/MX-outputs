What the Audit Measures

The audit covers every dimension that affects how AI agents understand and interact with your site, mapped to the unified 0-5 MX readiness model.

Discovery

Can AI agents find and crawl your content?

  • Semantic HTML structure
  • Heading hierarchy
  • robots.txt and sitemap.xml
  • llms.txt presence
  • Server-side rendering

Citation

Can agents extract facts and attribute them?

  • Schema.org JSON-LD
  • Open Graph and meta tags
  • Structured data quality
  • Content freshness signals
  • Author and publisher markup

Search & Compare

Can agents compare your offerings with competitors?

  • Product and service markup
  • Feature and specification data
  • FAQ schema
  • Table structure quality
  • Data attribute clarity

Accessibility

WCAG 2.1 compliance — good for humans, essential for agents.

  • Pa11y automated testing
  • ARIA landmark coverage
  • Image alt text
  • Form label association
  • Colour contrast ratios

Performance

Speed and efficiency matter for every visitor — human or machine.

  • Core Web Vitals (LCP, CLS, TBT)
  • First Contentful Paint
  • Time to Interactive
  • Page weight and resources
  • JavaScript dependency

Security

Trust signals that agents and users both rely on.

  • HTTPS and certificate validity
  • Security headers (CSP, HSTS)
  • Mixed content detection
  • Cookie security
  • XSS vulnerability patterns
