The Problem

Machines cannot reliably act
on documents designed for human eyes.

Every enterprise AI deployment hits the same four failures.

Not a web problem. A document problem. Contracts, policies, manufacturing specs, government archives, scientific papers — the substrate of every enterprise.

  1. 01 Wasted inference Agents recompute meaning that should already be explicit.
  2. 02 Energy cost Ambiguous documents become a compute problem at scale.
  3. 03 Hallucinations Agents guess when source material is ambiguous. An infrastructure problem, not a model problem.
  4. 04 No provenance No way to verify origin or whether a document has been altered.

Cogs are a small set of declarations a document makes about itself — carried in plain text, in the file, before the prose begins.

IdentityWHO & WHAT
Title, author, publisher, version. The same fields a librarian has cataloged for two centuries — now structured, so a machine can read them too.
ProvenanceHOW IT CAME TO BE
Human-directed or agent-generated. The boundary regulators now require, and the one no incumbent can answer for legacy content.
ConformanceRULES IT FOLLOWS
The standards the document promises to obey — schema.org, Dublin Core, MX core. An agent can verify the promise before acting on the contents.
